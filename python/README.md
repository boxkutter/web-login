# boxkutter-web-login (Python)

The server side of web-login. See the repository README for what it does and how to use it.

Optional extras: `fastapi` (the routers), `async` (the async router in `web_login.api_async`, for apps on SQLAlchemy's async engine), `redis` (`RedisLimiter`), `dev` (tests). Checks: `.venv/bin/ruff check . && .venv/bin/pytest`.
